# confyaml

Инструмент командной строки, который переводит текст на учебном
конфигурационном языке в YAML. Вход читается из стандартного ввода,
результат пишется в стандартный вывод.

## 1. Общее описание

Разбор выполняется библиотекой [Lark](https://github.com/lark-parser/lark)
(LALR, грамматика в `src/confyaml/grammar.py`). Программа работает в
три шага.

1. `parser.py` строит дерево разбора и сообщает о синтаксических ошибках.
2. `evaluator.py` вычисляет значения и константные выражения.
3. `translator.py` выводит результат в YAML через PyYAML.

Структура репозитория:

```
src/confyaml/   исходный код
tests/          модульные тесты (unittest)
examples/       два примера .conf и ожидаемый .yaml
Makefile        install, run, test
run.sh          запуск без установки пакета
```

## 2. Описание всех функций и настроек

Настроек у программы нет, есть только `-h`. Ошибки выводятся в stderr
в виде `Ошибка: строка N, столбец M: текст`, код завершения 1.

### Синтаксис языка

| Конструкция | Запись | Результат в YAML |
|---|---|---|
| Комментарий | `# текст до конца строки` | игнорируется |
| Число | `0b101`, `0B11` | десятичное целое |
| Строка | `[[Это строка]]` | строка (может быть многострочной) |
| Массив | `<< 0b1, 0b10, >>` | список |
| Словарь | `table( имя => значение, )` | словарь |
| Константа | `имя is значение` | в вывод не попадает |
| Выражение | `^{имя 0b1 +}` | вычисленное значение |

Правила.

- Имена: `[a-zA-Z][a-zA-Z0-9]*`. Слова `is`, `table` и `sqrt` зарезервированы.
- После последнего элемента массива и словаря допустима запятая.
- Значения вкладываются друг в друга без ограничений.
- Константу нужно объявить до использования. Повторное объявление
  запрещено. Имя в словаре тоже не должно повторяться.
- Значение константы подставляется только через `^{имя}`.
- Верхний уровень файла это объявления и значения. Одно значение
  выводится как есть, несколько как список, ни одного даёт пустой вывод.

### Выражения `^{...}`

Запись постфиксная. Внутри допустимы числа `0b...`, десятичные целые
(как в примере `^{имя 1 +}`), имена констант и операции.

| Операция | Действие |
|---|---|
| `+` | сложение двух чисел |
| `-` | вычитание, `a b -` это `a - b` |
| `*` | умножение |
| `sqrt` | квадратный корень, результат вещественный |

В конце на стеке должно остаться ровно одно значение. Операции
принимают только числа.

### Внутренние функции

| Функция | Назначение |
|---|---|
| `parser.parse(text)` | текст в дерево Lark, ошибки в `ConfigError` |
| `Evaluator().run(tree)` | дерево в список значений верхнего уровня |
| `translator.translate(text)` | текст конфигурации в текст YAML |
| `translator.to_yaml(values)` | значения в YAML |
| `cli.main(argv, stdin, stdout, stderr)` | CLI, возвращает код завершения |

## 3. Сборка и запуск тестов

Нужен Python 3.10 или новее.

```
make install    # pip install -r requirements.txt
make test       # python -m unittest discover -s tests -v
```

Без make:

```
pip install -r requirements.txt
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

## 4. Примеры использования

```
./run.sh < examples/webservice.conf
./run.sh < examples/triangle.conf > triangle.yaml
echo 'x is 0b11 ^{x x * sqrt}' | ./run.sh
```

Пример 1, настройка веб-сервиса (`examples/webservice.conf`):

```
port is 0b1111101000
workers is 0b100
timeout is ^{port 0b11 *}

table(
    service => [[shop-api]],
    listen => table(host => [[0.0.0.0]], port => ^{port}),
    pool => table(
        workers => ^{workers},
        queue => ^{workers 0b1000 *},
        limits => << ^{workers 1 +}, 0b1010, ^{timeout} >>
    ),
    hosts => << [[a.example.com]], [[b.example.com]] >>
)
```

Результат:

```yaml
service: shop-api
listen:
  host: 0.0.0.0
  port: 1000
pool:
  workers: 4
  queue: 32
  limits:
  - 5
  - 10
  - 3000
hosts:
- a.example.com
- b.example.com
```

Пример 2, геометрия (`examples/triangle.conf`): гипотенуза считается
как `^{a a * b b * + sqrt}`, результат смотрите в `examples/triangle.yaml`.

Пример ошибки:

```
$ echo 'table(a => 0b1 b => 0b1)' | ./run.sh
Ошибка: строка 1, столбец 14: неожиданная лексема 'b'
```
